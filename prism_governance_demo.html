Effective Skill Contract

运行时合同 = 共享 invariant + Skill 能力 + 本地约束 + 任务引用。

1

Shared Governance Invariants

授权、状态晋级、写入、handoff、停止边界。跨多个 Workflow Skill 稳定成立。

2

Skill Capability

Clarify 问一个阻塞取舍；Review 形成证据判断；Scope 更新合同。

3

Skill-local Constraints

进入条件、跳过条件、写入面、stop / ask / fallback、局部禁止面。

4

Task-specific References

scope.md、focus.md、review rXX、decision dXX、handoff contract 等上下文材料。

共享运行时 Invariants

高亮项表示当前场景最容易出错、最需要 Agent 稳定加载的边界。

AUTH只认明确授权
CANDIDATE候选不是决定
ADVANCE不自动晋级状态
HANDOFF交接不携带权力
WRITE写入 fail-closed
INSPECT先调查再提问
STOP前置缺失即停止

迁移矩阵视角

用这四类判断一条规则应该留在 Skill、上提共享、延后删除，还是直接删。

KEEP Skill 独有能力、过程、写入面和局部安全锚。
MOVE 跨多个 Workflow Skill 稳定成立的 runtime invariant。
DEFER_DELETE 已上提但 pilot 仍要保留的安全字段或提示。
DELETE 同一文件内没有独立安全价值的纯重复表达。

边界调试台

用“允许 / 等待 / 禁止”表达治理结果，减少抽象规则的阅读负担。
